# Streamlit Test Project

Учебное multi-page приложение на Streamlit для загрузки, просмотра и анализа CSV/Excel-файлов с товарами.

## Возможности

- Загрузка данных из `.csv` или `.xlsx` файла
- Проверка структуры файла (наличие обязательных колонок)
- Просмотр исходных данных и сводки по категориям (сумма цен)
- Просмотр статистики по датасету (`describe()`)
- Фильтрация товаров по категории
- Визуализация цен: гистограмма и линейный график

## Структура проекта

```
Streamlit-test-project/
├── app.py              # Главная страница — выбор категории
├── pages/
│   ├── raw_data.py     # Загрузка и просмотр исходных данных
│   └── carts.py        # Фильтрация по категории и графики
└── README.md
```

## Требования к загружаемому файлу

Файл должен содержать следующие колонки:

- `product` — название товара
- `price` — цена
- `category` — категория товара

Поддерживаемые форматы: `.csv`, `.xlsx`.

## Установка и запуск

```bash
pip install streamlit pandas matplotlib openpyxl
streamlit run app.py
```

## Как пользоваться

1. Откройте страницу **raw_data** и загрузите файл с данными.
2. Перейдите на страницу **carts**, выберите нужную категорию.
3. Просмотрите распределение цен на вкладках «Гистограмма» и «Линейный график».

## Технологии

- [Streamlit](https://streamlit.io/) — интерфейс и навигация
- [pandas](https://pandas.pydata.org/) — обработка данных
- [matplotlib](https://matplotlib.org/) — визуализация
